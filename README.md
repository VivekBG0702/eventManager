# EventManager

EventManager is a full-stack event management system built with React, FastAPI, and MySQL.

## Features

- Admin module
- Coordinator module
- Student module
- Role-based authentication
- Event creation and management
- Event registration
- Student event registrations
- QR-based attendance
- Coordinator attendance management
- Certificates
- Notifications
- MySQL database integration

## Technology Stack

### Frontend
- React
- JavaScript
- CSS
- Vite

### Backend
- Python
- FastAPI
- SQLAlchemy

### Database
- MySQL
